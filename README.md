# Fidget

Install the Apple Silicon cask.

```sh
brew install --cask omesser/fidget/fidget
```

`brew update` and `brew upgrade --cask fidget` follow the latest GitHub Release of [Fidget](https://github.com/omesser/fidget).

`Casks/fidget.rb` is a copy of `packaging/homebrew/Casks/fidget.rb` in that repo. After a bump there, copy the cask here and push it.
